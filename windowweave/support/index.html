Permissions

WindowWeave needs two macOS permissions. After you grant them the first time, quit and reopen the app if shortcuts do not respond.

  • System Settings → Privacy & Security → Accessibility → WindowWeave
  • System Settings → Privacy & Security → Input Monitoring → WindowWeave

How to try the basics

  1. Launch WindowWeave. It appears in the menu bar (no Dock icon).
  2. Grant Accessibility and Input Monitoring, then quit and reopen once.
  3. Use a menu-bar window command with Finder or TextEdit frontmost.
  4. Drag any window and hold Command (⌘). Drop onto a layout zone, or press Esc to cancel.
  5. Menu bar → Remember Current Workspace, then restore it. A receipt lists verified / adjusted / skipped windows.
