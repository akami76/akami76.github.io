WindowWeave privacy policy

Last updated: 31 August 2026

WindowWeave is a local-only macOS app. It has no account, no network features, and no analytics.

What we process

Only to arrange windows and restore workspaces you choose to save:

  • Running app names and bundle identifiers
  • Standard Accessibility window titles, role, and subrole
  • Window position, size, and display identifiers

This information is stored on this Mac only when you choose “Remember Current Workspace,” at ~/Library/Application Support/WindowWeave/scenes.json.

What we do not collect

  • Screen pixels or screenshots
  • Document contents or file contents
  • Keystroke contents (the input monitor only detects Command-drag, shortcuts, and Esc)
  • Browser history, contacts, or location
  • Anything sent to a server — there is no server

Tracking

WindowWeave does not track you, does not use advertising identifiers, and does not share data with third parties.

Deleting stored data

Quit WindowWeave, then delete ~/Library/Application Support/WindowWeave/scenes.json.

개인정보 처리 원칙 (한국어)

WindowWeave는 로컬 전용으로 동작하며 네트워크 기능을 포함하지 않습니다. 창 제목과 위치는 “현재 작업공간 기억”을 선택할 때만 이 Mac에 저장됩니다. 화면 픽셀, 문서 본문, 키 입력 내용은 저장하거나 전송하지 않습니다.

저장 데이터를 지우려면 앱을 종료한 뒤 위의 scenes.json 파일을 삭제하면 됩니다.
